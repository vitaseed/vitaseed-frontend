# The Gami Co. 🌱

The Gami Co. is a nutrition-focused seed brand website built as a teaser/MVP.
The project allows users to explore products and send enquiries.

## 🌿 Features
- Product listing
- Enquiry (contact) form
- Clean teaser-style UI
- Free hosting

## 🧱 Tech Stack
- HTML, CSS, JavaScript
- GitHub Pages (Frontend Hosting)
- Render (Backend API)
- Firebase Firestore (Database)

## 🔗 Live Website
Hosted on GitHub Pages

## ⚠️ Note
This is an early-stage teaser version.  
Responses to enquiries may take time.
